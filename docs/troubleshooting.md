# Troubleshooting

| Symptom | Action |
|---|---|
| New article covers old release | Check original event date; reject outside 96 hours |
| Only rumors found | Save candidate rejection report and skip |
| Image tool unavailable | Save reviewed copy/prompts; report missing image capability |
| Slide typo or wrong number | Regenerate the affected slide with a targeted correction, update hash, rebuild PDF |
| Mixed style across slides | Use a viewed style reference and shared prompt; inspect again |
| PDF pages out of order | Fix manifest, not lexical assumptions; rebuild and verify pixels |
| Browser upload denied | Respect denial; user must resolve host permission |
| PDF saved only locally | Upload through real supported tools and verify attachment |
| ScheduledTime omitted | It creates a draft; check schema before publishing |
| Post disappeared after schedule | Mark unknown and reconcile; do not blindly recreate |
| Analytics inaccessible | Record unavailable and current access limitation |
| Scheduler not running | Check host execution environment/gateway and last actual run |
| Example no longer fresh | Use new live evidence; never update its date to pretend freshness |

No success claim should depend on a screenshot of a local file alone. Draft attachment, scheduled record and public LinkedIn delivery are distinct states.
