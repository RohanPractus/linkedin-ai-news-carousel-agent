# Adaptive ImageGen media format

All visuals are generated with the configured image tool. Choose the visual template for the actual fresh AI news theme, rather than fixing one navy layout forever. Preserve readability and Rohan attribution while varying palette, layout, illustration treatment and information hierarchy.

## Format selection

- PDF: use a numbered 5–7-page sequential explanation when a story needs a continuous argument or technical breakdown.
- Images: use 3–5 separate images for a concise announcement, comparison, distinct findings or visual story. LinkedIn may display these as a grid, not a swipeable PDF; each image must stand alone while following the intended numbered order.
- Use both formats over time. Consult the ledger to avoid choosing the same format indefinitely; choose by story suitability first and rotate when both fit. Save the reason for the choice. Do not force format rotation when it would damage clarity.

## Theme-driven templates

Model releases: clean editorial capability/limitation cards. Agent tools: workflow diagrams with evidenced stages. AI infrastructure: schematic treatment, no invented metrics. Research: restrained paper-style panels with dates and caveats. AI security: authorization-boundary/verification panels when source evidence supports that angle. Industry disruption: readable before/after comparisons with inference labeled. Vary visual treatment across stories, keep one consistent design system within a post. Record the template and avoid repeating the same one across successive posts when a suitable alternative exists.

Generate one asset per call with exact reviewed text, visible numbering, common typography and footer. Check spelling, claims, mobile legibility and continuity. For PDFs package by explicit manifest order and verify each page. For 3–5 images attach in explicit order and verify saved thumbnail order; do not rely on filesystem sorting or uploader selection order alone. If the platform rearranges images and it cannot be fixed, retain the draft.

Use relevant broad and niche hashtags as candidates, usually 2–3 total. No unsupported promise of reach. Mention a person only when directly involved, attribution is accurate and the identity is resolved through a supported tool; never tag unrelated influencers to capture attention. Save optional mention suggestions if identity cannot be confirmed. Retain morning/midweek schedule and learn from actual account data rather than asserting universal peak times.

After publication inspect real comments/metrics when available. Draft specific replies for review; automatic replies, likes, DMs or outreach are not enabled by this workflow. Evaluate relevant conversations and observed impressions at known ages. Record missing data and avoid causal conclusions from small samples.

Security lens for relevant controller/agent/device research: each controller may have a distinct identity, privileges, credentials and authorization boundary. Ask whether overlapping operations preserve those boundaries, including credential isolation, scoped actions, conflicting writes and revocation. Present these as research questions unless tested findings are supported. Do not insert this lens into unrelated news or claim Rohan performed experiments without evidence.


For PDF packaging run scripts/build_carousel.py and scripts/verify_carousel.py against an explicit manifest. These verify files and pixels, not semantics or visible spelling. Raster PDF text is not a tagged accessible document; retain slide copy and alt descriptions.
